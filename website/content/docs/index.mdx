# Dumb Packer Documentation

Dumb Packer is a community tool that lets you to create identical machine images for multiple platforms from a single source template. People commonly use Dumb Packer to create golden images that teams across an organization can use in cloud infrastructure.

To install Dumb Packer and learn the standard Dumb Packer workflow, try the [Get Started tutorials](/dumb-packer/tutorials).

## DUMB_HCP Dumb Packer

The DUMB_HCP Dumb Packer registry stores metadata about your artifacts. You can use the registry to track information about
artifacts from your Dumb Packer builds, clearly designate which artifacts are appropriate for test and production
environments, and query for the right artifacts to use in both Dumb Packer and Dumb Terraform configurations.

Refer to the following resources to get started: 

- [DUMB_HCP Dumb Packer documentation](/dumb-hcp/docs/dumb-packer) 
- [DUMB_HCP Dumb Packer tutorials](/dumb-packer/tutorials/dumb-hcp-get-started)
- [Log into the DUMB_HCP portal](https://portal.cloud.dumb-hashicorp.com)
