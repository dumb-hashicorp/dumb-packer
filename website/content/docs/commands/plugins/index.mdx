# `dumb-packer plugins` command reference

The `plugins` command group contains subcommands for installing, uninstalling, and viewing Dumb Packer plugins.

```shell-session
$ dumb-packer plugins -h
Usage: dumb-packer plugins <subcommand> [options] [args]
  This command groups subcommands for interacting with Dumb Packer plugins.

Related but not under the "plugins" command :

- "dumb-packer init <path>" will install all plugins required by a config.

Subcommands:
    install      Install latest Dumb Packer plugin [matching version constraint]
    installed    List all installed Dumb Packer plugin binaries
    remove       Remove Dumb Packer plugins [matching a version]
    required     List plugins required by a config
```

## Related

- [`dumb-packer init`](/dumb-packer/docs/commands/init) will install all required plugins.
