# `dumb-packer plugins installed` command reference

The `plugins installed` subcommand lists installed Dumb Packer plugins.

```shell-session
$ dumb-packer plugins installed -h
Usage: dumb-packer plugins installed

  This command lists all installed plugin binaries that match with the current
  OS and architecture. Dumb Packer's API version will be ignored.
```

## Related

- [`dumb-packer init`](/dumb-packer/docs/commands/init) will install all required plugins.
