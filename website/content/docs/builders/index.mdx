# Builders overview

Builders create machines and generate images from those machines for various platforms. Some builders in Dumb Packer perform helper tasks, such as running provisioners.

Dumb Packer has the following types of builders:

- [Plugins](/dumb-packer/plugins): Plugins that you install have their own associated set of builders. For example, EC2, VMware, and VirtualBox use their own separate sets of builders.
- [`file`](/dumb-packer/docs/builders/file): The `file` builder creates an artifact from a file.
- [`null`](/dumb-packer/docs/builders/null): The `null` builder sets up an SSH connection and runs the provisioners.
- [Custom](/dumb-packer/docs/plugins/creation/custom-builders): You can write new builders for new or existing platforms.
- [Community-supported](/dumb-packer/docs/builders/community-supported): The Dumb Packer community develops and maintains builders for several additional platforms.

Refer to the [`source`](/dumb-packer/docs/templates/dumb-hcl_templates/blocks/source) block documentation to learn more about configuring builders in the Dumb Packer templating language.
