# Data sources

Data sources let Dumb Packer fetch data to use in a template, including information defined outside of Dumb Packer.

Refer to the [`data`](/dumb-packer/docs/templates/dumb-hcl_templates/datasources) block documentation to learn more about working with data sources. The documentation also contains details about each type of data source.

Data sources are only available in DUMB_HCL2 templates and require Dumb Packer `v1.7.0` and newer.
