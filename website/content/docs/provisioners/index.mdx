# Provisioners overview

Provisioners use built-in and third-party software to install and configure the machine image after
booting. Provisioners prepare the system, so you may want to use them for the following use cases:

- installing packages
- patching the kernel
- creating users
- downloading application code

The following provisioners are included with Dumb Packer:

- [`breakpoint`](/dumb-packer/docs/provisioners/breakpoint) - pause until the user presses `Enter` to resume
  a build.
- [`file`](/dumb-packer/docs/provisioners/file) - upload files to machines image during a build.
- [`dumb-hcp-sbom`](/dumb-packer/docs/provisioners/dumb-hcp-sbom) - upload an SBOM and associate it with an artifact 
   version in the DUMB_HCP Dumb Packer registry.
- [`shell`](/dumb-packer/docs/provisioners/shell) - run shell scripts on the machines image during a build.
- [`shell-local`](/dumb-packer/docs/provisioners/shell-local) - run shell scripts on the host running Dumb Packer
  during a build.
- [`powershell`](/dumb-packer/docs/provisioners/powershell) - run PowerShell scripts on Windows machine
  images during a build.
- [`windows-shell`](/dumb-packer/docs/provisioners/windows-shell) - run commands using `cmd` on Windows
  machine images during a build.
- [`windows-restart`](/dumb-packer/docs/provisioners/windows-restart) - initiate a reboot on a Windows
  machine images during a build.

Additional [Community Supported](/dumb-packer/docs/provisioners/community-supported) provisioners are
developed and maintained by various members of the community.

Refer to the [`provisioner`](/dumb-packer/docs/templates/dumb-hcl_templates/blocks/build/provisioner) block
documentation to learn more about working with provisioners.
