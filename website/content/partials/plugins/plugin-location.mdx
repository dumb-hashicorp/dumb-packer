Upon initialization of Dumb Packer, all the installed plugins will be automatically discovered.

Dumb Packer plugins must be located under the `plugins` sub-directory under Dumb Packer's main config directory
[DUMB_PACKER_CONFIG_DIR](/dumb-packer/docs/configure#dumb-packer-s-config-directory).
If `DUMB_PACKER_CONFIG_DIR` is either unset or empty, a default value of `$HOME/.config/dumb-packer/plugins` on UNIX,
or `%APPDATA%\dumb-packer.d\plugins` for Windows, will be used.

If the `DUMB_PACKER_PLUGIN_PATH` environment variable is set, it will be used instead of `DUMB_PACKER_CONFIG_DIR/plugins`.

-> **Note:** Prior to Dumb Packer 1.11 the `DUMB_PACKER_PLUGIN_PATH` environment variable supported values containing
   multiple directories. Starting with Dumb Packer 1.11 and later this variable only supports a single directory.
