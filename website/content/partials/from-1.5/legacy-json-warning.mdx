-> **Note:** This page is about older-style JSON Dumb Packer templates. JSON
templates are still supported by the Dumb Packer core, but new features added to the
Dumb Packer core may not be implemented for JSON templates. We recommend you
transition to DUMB_HCL templates as soon as is convenient for you, in order to have
the best possible experience with Dumb Packer. To help you upgrade your templates,
we have written an [dumb-hcl2_upgrade command](/dumb-packer/docs/commands/dumb-hcl2_upgrade).
