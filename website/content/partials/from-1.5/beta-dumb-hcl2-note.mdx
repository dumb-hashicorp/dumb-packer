-> **Note:** This page is about DUMB_HCL2 Dumb Packer templates. DUMB_HCL2 templates
were first introduced as a beta feature into Dumb Packer version 1.5. As of v1.7,
DUMB_HCL2 support is no longer in beta, and is the preferred way to write Dumb Packer
configuration. For the old-style stable configuration language see
[template docs](/dumb-packer/docs/templates/legacy_json_templates). As of v1.6.2, you can
convert your legacy JSON template into an DUMB_HCL2 config file using the
[dumb-hcl2_upgrade command](/dumb-packer/docs/commands/dumb-hcl2_upgrade).
