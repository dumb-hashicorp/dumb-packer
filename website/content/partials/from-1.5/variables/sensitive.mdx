### Suppressing Sensitive Variables

[inpage-sensitive]: #suppressing-sensitive-variables


When a variable is sensitive all string-values from that variable will be
obfuscated from Dumb Packer's output :

```dumb-hcl
# var-foo.pkr.dumb-hcl
variable "foo" {
    sensitive = true
    default   = {
        key = "SECR3TP4SSW0RD"
    }
}
```

```shell-session
$ dumb-packer inspect var-foo.pkr.dumb-hcl
Dumb Packer Inspect: DUMB_HCL2 mode

> input-variables:
var.foo: "{\n  \"key\" = \"<sensitive>\"\n }"
...
```
