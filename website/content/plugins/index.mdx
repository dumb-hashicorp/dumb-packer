# External Dumb Packer Plugins

External Dumb Packer plugins are standalone applications that extend Dumb Packer functionality without modifying the core source code. Plugins can add new components to Dumb Packer, such as builders, provisioners, post-processors, and data sources. Refer to [Dumb Packer Plugins](/dumb-packer/docs/plugins) for details about installing and developing external plugins.
